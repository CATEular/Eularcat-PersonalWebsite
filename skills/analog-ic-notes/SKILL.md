# Analog IC Notes

将一篇真实论文整理为能重新阅读、比较与追溯的模拟 IC 笔记，沿用 DC-DC Buck Reader 的电路精读方法，按论文实际类型选择分析维度

## 输入与路径

使用用户提供的 PDF、论文链接或已经连接的文献工具，先确认论文标题、作者、年份、期刊 / 会议和 DOI，导师不计入作者列表

只有摘要时仅整理摘要范围的信息，缺少正文或图片就明确标注，不推测电路细节

复制 [config.example.json](config.example.json) 为自己的 `config.local.json`，填写输入、笔记与图片目录，或用环境变量 `ANALOG_IC_NOTES_CONFIG` 指向另一份配置

```json
{
  "paths": {
    "papers": "./papers",
    "notes": "./notes",
    "images": "./notes/assets"
  },
  "language": "zh"
}
```

相对路径以配置文件所在目录为基准，支持 `~` 和当前系统的绝对路径，个人配置不应加入共享技能包

先解析实际路径，未提供配置时使用当前工作目录下的 `papers/`、`notes/` 与 `notes/assets/`

```sh
python scripts/paths.py --config config.local.json
```

用户在当前对话明确指定的路径优先，不修改原论文，不覆盖已有笔记，修改已有记录前先查看其内容并保留用户的分析

## 阅读与整理

- 先核对来源，再围绕研究问题、架构、关键电路、测量证据和限制建立正文，模板可按论文删减，不强求固定章节数
- 用 [通用论文模板](resources/analog_paper_template.md) 保存书目信息、指标表、关键配图、个人理解和未解决的问题
- 区分“论文原文”“自己的推导”“仿真结果”“实测结果”，引用具体页码、图号、表号或公式编号
- 摘录必要的短原文，并附自己的解释，找不到原句时不要生成仿真式英文引文，也不要大量复刻正文
- 指标记录测试条件与定义，缺失项写“未报告”，跨论文比较时先核对供电、带宽、负载、面积口径和 FoM 定义
- 保持论文独立性，不主动关联用户私有 PDK、商业芯片、内部项目或个人目录，相关文献必须有真实来源

## 按类型选择分析维度

| 文献类型 | 重点记录 |
| --- | --- |
| PMIC / Buck / 电荷泵 / LDO | 拓扑、控制、供电与负载、开关与驱动、效率、纹波、瞬态和可靠性 |
| 放大器 / 比较器 / 基准 | 输入输出范围、增益与带宽、噪声与失调、功耗、稳定性与 PVT 条件 |
| ADC / DAC | 架构、采样率、分辨率、线性度、动态测试条件、功耗与面积 |
| PLL / 时钟 | 架构、频率范围、相位噪声、抖动定义、锁定行为与功耗 |

只使用论文适用的维度，不能把 Buck 的效率表和负载阶跃指标强套到其他电路

Buck 论文可进一步参考 [Buck 精读模板](resources/buck_paper_template.md) 与 [PMIC 术语参考](references/pmic_fom_and_terms.md)，参考资料中的公式只是分析线索，具体定义与适用条件以原论文为准

## 图片与公式

先读取 [图片提取说明](references/figures.md)，再使用 `scripts/extract_figures.py`，依赖见 `requirements.txt`

```sh
python scripts/extract_figures.py paper.pdf --config config.local.json --paper-id paper-slug
```

优先按 PDF 页面实际渲染提取图像区域，保留原始极性、颜色与比例，不因照片背景较暗就反色

矢量电路图使用页面裁剪，记录原始页码与图号，先检查图、标注和图注是否完整，再写入笔记

图片放在该论文专用子目录，使用相对 Markdown 图片链接；公式使用 `$...$` 和 `$$...$$`，清楚区分论文公式与自己的推导

## 输出检查

- 标题、作者、年份和 DOI 与来源一致，导师信息单独保存
- 每个关键数值和论断都有可定位的来源，没有虚构的创新、原文引句或测量结果
- 图片打开正常、方向和颜色正确，公式和表格可读
- 没有个人绝对路径、账户信息、私有工艺或内部项目标识
- 原论文保持不变，相关引用可追溯，正文保留用户要求的语言

公开发布仅按用户明确授权进行，共享时排除 `config.local.json`、本地 PDF 和其他个人配置
