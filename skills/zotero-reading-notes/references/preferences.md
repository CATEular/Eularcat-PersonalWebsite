# 首次安装：让 AI 了解你的笔记习惯

每个人的颜色和目录习惯不同。首次使用先问一句：

> 你的 Obsidian 文库和论文笔记放在哪里？批注颜色分别代表什么（也可以不按颜色分类）？想用什么语言、整理多详细，需要知识卡吗？

已有偏好时只补齐缺失项。用户在当前对话里明确指定的偏好优先；不必每篇重问。颜色暂未确定时，保留颜色信息并按评论和上下文整理；目标位置未确定时先交付对话草稿，不猜文库。

## 保存配置

将 `config.example.json` 复制为 skill 目录下的 `config.local.json`，由 Agent 根据用户确认的值编辑。它是 Agent 读取的偏好文件；证据提取脚本不读取这份配置。

| 字段 | 含义 |
| --- | --- |
| `paths.vault` | 用户确认的 Obsidian 文库根目录；空值表示尚未配置 |
| `paths.notes` | 论文笔记目标目录；空值表示尚未配置 |
| `annotations.useColorMeaning` | 是否依据颜色赋予语义；选择启用前先确认映射 |
| `annotations.colorMeanings` | 颜色十六进制值到用户自定义含义的映射 |
| `notes.language` | 笔记语言，如 `zh` 或 `en` |
| `notes.detail` | 整理详略，如 `concise`、`detailed`，也可用自然语言描述 |
| `notes.knowledgeCards` | 是否补充相关知识卡；开启后仍先检查已有概念与别名 |

所有相对路径以配置文件所在目录为基准。可按用户需要填写绝对路径；使用前解析、核对实际目录，不自动新建一套文库结构。

## 可选的颜色示例

下面只是一种阅读习惯，不是默认规则。用户可以交换含义、增加颜色，或完全不用颜色分类。

| 颜色 | 示例含义 |
| --- | --- |
| 红 `#ff6666` | 待解决问题 |
| 绿 `#5fb236` | 针对问题的方案 |
| 黄 `#ffd400` | 重要知识 |
| 蓝 `#2ea8e5` | 定义 |

用户明确选择这组含义后，才将其写入 `colorMeanings` 并启用 `useColorMeaning`。没出现在映射中的颜色仍不猜含义。同一颜色的具体评论优先于颜色标签；问题与方案之间的关系也需要原文证据支持。

个人配置仅保存在本机。升级时保留 `config.local.json`，不要以示例文件覆盖它；分享 skill 或笔记模板时排除此文件、真实文库路径及证据数据。
