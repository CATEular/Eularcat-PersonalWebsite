# 用户默认绘图风格

普通信号使用连续导线从器件端子接到另一个端子，尽量不给内部线命名。VDD、GND/VSS 等公共电源可用全局符号和名称；接口 pin、差分接口、用户明确要求的测量节点可保留名称。仿真器自动产生 net1/net2 不等于画图必须显示这些名字。

先安排左输入右输出、上供电下地；相同信号行上的端子对齐，而不是只对齐器件原点。短线、正交线优先，转折尽量少；跨线避免制造假连接，真实分支明确接到同一节点。不用命名断线掩盖复杂排布。

默认紧凑排布。以 master 的实际图形、端子和可见参数文字占用范围确定间距，不给每个器件套固定的大网格。相邻级共享短连接；互补上下管靠近，负载贴近本级输出；供电轨与反馈线只留必要通道。先排一个完整功能单元再重复，适当分行或用已生成的层级 symbol 处理超宽电路。Zoom Fit 后器件轮廓、实例名和关键参数应能辨认，不能只有大片空白和细长导线；保留足够距离防止文字重叠和误短路。几何收紧后再次读回连通性，并复测最终电路。

从 master 的 terminal pin figure 读取中心，经实例 transform 得到真实端点。需要多次转弯时，本机 bridge 的 `schCreateWire(... "route" "full" list(...))` 实测忽略后续拐点；对每两个相邻点分别调用 `schematic_create_wire`，或验证本版本支持的其它画线模式。两端直接相连的 `schematic_create_wire_between_instance_terms` 已通过测试。

完成后 Check & Save，并读回每个实例 terminal 的 net，检查接口 pin 没有空连接、应共网的端子确实共网、没有非预期短路。最后缩放并截图检查拥挤、文字遮挡和多余折线。本机适配窗口使用 `schZoomFit(0.9 0.9)`；不要调用本机不存在的 `geFit()`。

已验证的 RC/TB/MOS 样图属于当时配置中的工作库测试 cells，采用直接数据库创建，不是从 netlist 导入。重画后再运行 RC 仿真验证电气等价。


实际 OSC 排版曾从级间距5/上下间距4压到3/1.75，用户仍认为过散；最终按实际glyph缩至1.75/1.0，电容贴近输出，电源轨靠近源端，反馈仅留外圈通道。紧凑度以图形与文字可读为依据，不把这些数据库距离当通用物理尺寸或所有PDK模板。删除重复大号MOS说明，电容额外说明移到地线下方，避免遮挡CDF数值。

编辑后返回view bbox改变而像素仍旧时，本机仅redraw/hiFlush无效；保存并只关闭自己的该原理图，再geOpen同cell，新的绘图上下文已成功刷新。准确示例和版本边界见 [能力记录](../../virtuoso-connect/references/runtime-capabilities.md)。保留最终Maestro和ViVA，打开新原理图后再次截图视觉确认。

## 已采用的标注格式与推荐参数

沿用用户认可的最终 OSC 风格：器件按功能紧凑排列，原生实例名和 CDF 参数留在器件附近；只补充必要说明，不重复放大 MOS 标签。公共电源说明放在上方，电路概况与推荐参数放在电路下方或旁边的空白区。使用 annotate/drawing 层的非电气文字，左对齐、统一字体和字号，按短行分组；不遮挡器件、接点、连线或参数。不要为了加入说明重新拉开器件间距。当前示例用 roman、字号0.125、行距约0.23数据库单位；其他 PDK/窗口按实际可读性调整。

闭环调参得到可行结果并独立复测后，在目标 DUT/TB 的原理图中保存 `Recommended (verified)` 注释，不能只留在聊天、ADE 变量或暂时波形窗口中。标明实际数值和单位，以及与复现有关的长度、负载、供电、模型角点、温度、关键实测指标、日期和最终 history/test（多 test 时写明目标）。不要把 Wn/Wp 宽度写成沟道长度，也不要把变量名 wn/wp 当作推荐数值。器件的变量表达式默认保留，便于继续调参。

示例格式：

```text
Recommended (verified)
Wn = 1.3um | Wp = 2.6um | L = 180nm | C/stage = 480fF
VDD = 1.8V | TT, 27C | f = 100.480MHz | Vpp = 1.801V | Pavg = 0.823mW
Result: Interactive.7 / TRAN | 2026-10-08 | Wp = 2*Wn
```

这些数值仅是本次 OSC 的已验证例子，不是其他电路的默认尺寸。给 Agent 管理的推荐标签加可识别属性（本机已实测 `codexPurpose="recommended_params"`），后续更新只替换同一目标的这些标签，不重复堆叠或删除用户标注。参数/模型改动后，旧标注是历史验证记录，不能声称代表当前 ADE；需要保留时写明历史条件，在新结果独立复测后更新推荐。仅探索且未写回时注明推荐未应用；无可行点时不生成“已验证推荐”。

保存后读回文字及最终 history，并比较修改前后器件 property、位置与 terminal/net、接口 pin，确认注释没有改变电路。仅增加文字不必重复仿真；电气、几何或模型更改仍按相应验证流程处理。最后截图确认各行完整可读，原理图、Maestro 与最终波形保持打开。
