# EDA 文档帮助

解释术语、定位命令或查规则时优先使用对应产品版本的 Cadence/PDK 本地文档。记录文档名和可核对的位置；没有原文时不声称已经验证。

用户要求给 PDF 加目录/书签时：

1. 用实际可用的 PDF 技能及其运行环境读取页数、文本层和已有目录。
2. 识别或读取用户给定的目录，核对印刷页码与 PDF 页码偏移。扫描文件按当前工具条件选择 OCR，并报告不确定性。
3. 使用已安装库支持的 bookmark API，写入新副本并保留原文件。中文编码和 destination 类型按当前库签名验证，不采用旧日志中的绝对规则。
4. 重新打开结果，抽查中文标题、层级、目标页和已有目录是否保持。

旧 cookbook 的 PDF 经验已归入这个流程；不宣称 pikepdf 是唯一可靠的库，也不要求无关 EDA 任务先处理 PDF。
