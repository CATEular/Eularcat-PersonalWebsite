# Glossary

**ADE** — Analog Design Environment for analysis setup, outputs, expressions, and simulation control (Ch 3).

**Bindkey** — Context-sensitive keyboard shortcut mapped to a Virtuoso command (Ch 2–5).

**cds.lib** — Library definition file that maps logical library names to directories (Ch 1).

**CIW** — Command Interpreter Window, the main Virtuoso control window (Ch 1).

**DRC** — Design Rule Check; verifies layout against process geometry rules (Ch 6).

**DSPF** — Detailed Standard Parasitic Format used for extracted post-layout simulation (Ch 6).

**GPDK** — Generic Process Design Kit used by the RAK as a representative process (Ch 1).

**LMB** — Left Mouse Button (Ch 4).

**LVS** — Layout Versus Schematic comparison of devices and connectivity (Ch 6).

**Navigator** — Layout assistant for finding nets, pins, objects, and XL connectivity status (Ch 5).

**PDK** — Process Design Kit containing device libraries, models, constraints, and verification decks (Ch 1).

**PR Boundary** — Layout boundary that encloses the design; it must be selectable before stretching (Ch 4).

**Quantus** — Cadence parasitic extraction tool used to generate DSPF or Smart View (Ch 6).

**Smart View** — Quantus post-layout representation for extracted design data (Ch 6).

**ViVA** — Virtuoso waveform visualization and analysis environment (Ch 3).

**XL Status** — Navigator status information showing connectivity completion, including opens (Ch 5).
