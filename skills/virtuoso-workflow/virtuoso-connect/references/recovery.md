# 连接与 CIW 故障定位

| 现象 | 先检查 | 处理 |
|---|---|---|
| 无法导入 bridge | 当前解释器、安装路径、包版本 | 切换到已有专用环境；确需安装时按项目依赖安装 |
| SSH 失败 | 地址、用户、跳板、SSH 配置、网络 | 修正连接配置；认证材料不打印到日志 |
| 本机转发端口拒绝连接 | 隧道进程和端口是否存活 | 通过当前 bridge 的服务管理能力重建本次隧道 |
| 隧道在、远端拒绝连接 | Virtuoso 是否运行、远端 bridge 是否监听 | 使用当前启动输出中的初始化脚本路径加载 CIW |
| SKILL 调用超时 | 是否在做长任务、截图中的模态弹窗 | 先识别窗口；仅对已知本次弹窗使用当前版本的恢复接口 |
| CLI 成功但读回为空 | `result.ok`、函数返回契约、对象是否存在 | 不仅看进程退出码，读回并核对对象 |

模态弹窗可能阻塞整个 SKILL 通道。已安装 bridge 源码提供 `dismiss_dialog()`，但它可能确认多个窗口；先枚举/识别当前窗口，优先精确处理窗口。未知覆盖、删除、保存提示不能批量确认。桥接重启仅在确认连接故障时使用，不用重启掩盖长仿真。

CIW 输出和 Python 返回值是不同通道。`execute_skill()` 默认不负责向 CIW 回显；需要回显时显式打印，检查字符串格式与当前版本刷新行为。`%` 用格式参数或正确转义。多行结果优先结构化返回；旧串行化若处理换行不一致，使用明确记录分隔符并验证记录数量。
