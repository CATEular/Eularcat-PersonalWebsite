## 通用步骤

修改源文件，运行 `npm test`、`npm run build`、`npm run check`，然后使用 `npm run dev` 预览。部署时上传 `dist/`。

About 的中英文分别维护。论文和技术笔记保留原始语言，所有公开图片使用相对链接。源码仓库公开，草稿也应在提交前检查。
