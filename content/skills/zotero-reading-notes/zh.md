## 从读过的批注开始

给出论文标题、短名或 Zotero 链接，Agent 读取该篇原文和批注，把高亮、评论、框选与手绘整理成可回看的主题笔记。保留回到 PDF 原位置的链接，并区分论文内容、你的评论和 AI 解释。

适合“这篇刚读完，帮我整理一下”。再次运行时只补充新增或变化的内容，保留手工编辑；可按需补充已有知识卡。

## 安装与第一次配置

下载 ZIP，将解压后的 `zotero-reading-notes` 文件夹放入所用 Agent 支持的技能目录。准备可用的 Zotero 连接工具及 Obsidian 文库；本机离线提取可使用随附 Python 脚本，只需标准库。

首次调用时先配置自己的习惯，之后直接沿用。可以把下面这段交给 Agent：

> 使用 $zotero-reading-notes。先帮我配置 Obsidian 文库和论文笔记位置，确认各批注颜色的含义、笔记语言和详略，以及是否生成知识卡。保存为本地配置，再整理我指定的这篇论文。

将包内 `config.example.json` 复制为 `config.local.json`，由 Agent 根据你的回答填写。已有配置会保留；临时要求可以在当次对话中说明。

## 颜色由你定义

同样的红色，有人表示疑问，有人表示重要结论。技能先确认你的习惯，也支持完全不按颜色分类。未配置的颜色只作为来源信息保留，AI 依据评论与原文整理。

下面是一种可选示例，使用前需要你确认：

| 颜色 | 示例含义 |
| --- | --- |
| 红 | 待解决问题 |
| 绿 | 针对问题的方案 |
| 黄 | 重要知识 |
| 蓝 | 定义 |

你可以交换含义、添加颜色，或描述自己的分类方式。方案批注不自动表示问题已经解决，AI 仍需核对上下文与适用条件。

## 日常使用

> 帮我把《论文标题》当前的全部批注整理进 Obsidian，按我保存的偏好更新已有笔记，保留我的手工内容和待核问题。

笔记按主题组织，必要时补充精确的 Zotero 定位。证据不足的解释会注明待核实，框选和手绘需要结合页面查看。默认处理你指定的一篇论文；需要更详细的笔记或知识卡，可以在偏好中启用。

## 文件与本机数据

包内包含技能指令、偏好配置示例、首次设置说明、本机读取说明和只读证据提取脚本。个人配置、原文 PDF 和批注证据保存在自己的环境，分享或升级时保留并排除 `config.local.json`。

若连接工具无法完整读取批注，可请 Agent 按包内说明读取本机快照。脚本不写 Zotero 数据库；有歧义时先确认目标文献，未确认笔记位置时先给出草稿。
